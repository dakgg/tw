# 2026-09-12 작업일지

## 완료한 작업

- TypeScript npm 워크스페이스를 구성하고 Next.js 웹과 NestJS API를 구현했다.
- PostgreSQL/PostGIS용 Prisma 모델과 BullMQ·Redis 기반 6시간 주기 수집 구조를 추가했다.
- 서비스 목적을 한국 숙박업 운영자의 가격 의사결정으로 재정의했다.
- 개별 숙소명·평점·예약 상태를 제거하고, 운영 지역 반경의 익명 집계 시세로 데이터 모델을 변경했다.
- 서울 중구, 부산 해운대구, 제주시 운영 지역과 1·3·5km 반경 필터를 추가했다.
- 하단가·중앙값·평균가·상단가, 객실 유형별 중앙값, 가격 변동 및 검토 신호를 구현했다.
- 일본·중국·대만·미국의 공식 공휴일을 연도별로 생성하고 월간 달력과 다가오는 공휴일 목록을 추가했다.
- 국가별 방한 항공 예매율 추정치, 검색 비중, 좌석 공급 및 전주 대비 변화를 추가했다.
- 가짜 수요·시세·예매율·추천 데이터에 `(fake)`, `isFake: true`, `dataMode: "fake"` 표시를 적용했다. 공휴일에는 가짜 표시를 적용하지 않았다.
- Next.js `/api` 동일 출처 프록시를 구성해 웹 포트 하나로 대시보드와 API가 동작하도록 변경했다.
- 저장소 기여 지침 `AGENTS.md`와 실행 문서를 작성했다.

- 개발 서버: `http://localhost:3000`
- 로컬 네트워크: `http://172.30.1.63:3000`
- Cloudflare Quick Tunnel을 설치하고 임시 공개 주소를 발급했다.
- Quick Tunnel은 프로세스가 종료되거나 재실행되면 주소가 변경된다.
