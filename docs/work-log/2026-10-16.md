## Google Maps 실제 연동 완료

- 사용자 요청에 따라 브라우저용 키를 `apps/web/.env.local`에 등록했습니다. 파일은 Git 제외 및 소유자만 읽고 쓸 수 있는 권한으로 설정했으며 키 값은 문서에 기록하지 않습니다.
- Google Cloud 콘솔에서 Maps JavaScript API·Places API (New)가 활성화된 것을 확인했습니다. 기존 키의 허용 API를 해당 2개로 제한하고 HTTP 리퍼러를 `http://localhost:3000/*`로 제한해 저장 완료를 확인했습니다.
- 이미지 판독 시 발생한 키 대소문자 오기를 발급 원문과 대조해 수정했습니다.
- 컴퓨터 제어 권한이 정상 작동하여 Chrome의 로컬 화면에서 지도 표시, 장소 자동완성, 종각역 태양의정원 선택 후 반경 500m 주변 후보 20개 응답과 거리·이름·주소 표시를 확인했습니다. 이는 테스트 기준점이며 사용자 숙소의 실제 좌표로 확정하지 않았습니다.
- 검색 결과는 Google Places의 실제 응답이며 Airbnb 등록 여부·객실 유사성·날짜별 가격을 확인한 결과가 아닙니다. Airbnb 비교 데이터 연동은 여전히 미완료입니다.
- 기존 로컬 개발 서버가 환경변수를 반영한 것을 확인했습니다. 소스 코드 변경이나 외부 배포는 없습니다. 배포 도메인 허용 설정은 별도 필요합니다.
- 이전 기록의 권한·키 미설정으로 인한 검증 제한은 이번 지도·자동완성·주변 검색 확인으로 해소했습니다. 과거 수동 가격 계산 기능은 이미 제거되었으므로 해당 기능의 검증은 수행하지 않았습니다.
